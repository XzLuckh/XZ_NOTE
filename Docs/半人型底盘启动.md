# 底盘遥控与命令控制操作指南

## 一、遥控器控制

### 1.1 启动底盘

1. 按下底盘电源按钮
2. 打开急停开关

### 1.2 启动 Tracer（终端 1）

进入工作空间并编译环境：

```bash
cd ~/ROS/tracer_ws/
source devel/setup.bash
```

进入 `src` 目录并启动脚本：

```bash
cd src
./tracer.bash
```

### 1.3 查看话题与状态（终端 2）

新开一个终端窗口，同样需要 source 环境：

```bash
cd ~/ROS/tracer_ws/
source devel/setup.bash
```

查看话题列表：

```bash
rostopic list
```

实时查看底盘状态：

```bash
rostopic echo /tracer_rs_status
```

### 1.4 遥控器操作

1. 打开遥控器电源
2. 开机后将**左二按钮**拨下一格，即可开始遥控

> **注意：** 如果无法控制，请重启一次底盘后重试。

---

## 二、发布命令控制

### 2.1 设置 CAN 使能（终端 2）

进入控制工作空间的 `src` 目录：

```bash
cd ~/ROS/humanoid_control_ws/src
./can.bash
```

> **如果执行失败：** 返回上一级目录，source 环境后再执行：
>
> ```bash
> cd ~/ROS/humanoid_control_ws/
> source devel/setup.bash
> cd src
> ./can.bash
> ```

### 2.2 重启 Tracer（终端 1）

CAN 设置完成后，在终端 1 中**重新启动** `tracer.bash`：

```bash
./tracer.bash
```

### 2.3 发布导航控制命令

完成上述步骤后，即可通过发布导航控制命令来控制底盘运动。
